Tacco 是免费的吗？
Windows 安装包可免费下载，核心的贴边待办、截图钉屏、剪贴板历史、便利签、录音等功能均可免费使用。部分增值能力（如更大云同步空间、专属功能）以会员形式提供，但基础使用不收费。
Tacco 支持哪些操作系统？
当前提供 Windows 版，支持 Windows 10 与 Windows 11 桌面端。macOS 版本正在内测中。
我的待办和数据会不会丢？
本地数据保存在本机，开启账号云同步后会在登录的电脑之间同步备份。建议开启云同步以在多设备保持一致，并降低单机故障导致丢失的风险。
Tacco 和 TickTask 是什么关系？
Tacco 是产品的对外品牌名（原 TickTask）。出于商店重名等原因，2026 年正式更名为 Tacco；内部数据目录与账号体系保持兼容，老用户升级后数据不丢失。
怎么更新到新版本？
Windows 端支持应用内检查更新，检测到新版本后可按提示下载安装；也可在官网下载页获取最新安装包覆盖安装。
会员是什么？
会员是可选的增值服务，提供更大的云同步空间与部分专属能力，通过激活码兑换开通，基础功能不受会员限制。
截图钉屏和剪贴板历史会侵犯隐私吗？
截图、剪贴板与录音默认仅保存在本机或你的账号云空间，用于你自己的桌面效率提升。处理涉及敏感内容的剪贴板或截图时，建议按需清理。
