Tacco 版本更新记录

这里记录 Tacco（贴边待办工具）每个版本带来的变化，方便你了解演进与判断是否需要更新。

首页 › 更新日志

v0.4.84
最新
  • 鼠标移入屏幕顶部边缘自动展开晾衣绳，移出自动收起，支持在晾衣绳设置页面中启用/关闭。
  • 鼠标移入把手后自动展开工具主窗口，移出自动收起，支持在设置页面中启用/关闭。
  • 新增归档功能，在关闭随手记卡片、便利签、图片类卡片、番茄计时卡片时，支持选择归档，归档后，可在归档页面中查看和恢复。
  • 优化晾衣绳上的截图预览清晰度问题。
v0.4.82
  • 番茄计时卡片样式新增 6 种趣味卡片样式。
  • 晾衣绳最大长度可拉长至屏幕长度。
  • 晾衣绳新增 2 种样式，可通过更换拉杆样式进行切换。
  • 新增 Mac 电脑版本，Windows / macOS 双端均可下载使用。
v0.4.81
  • 新增晾衣绳功能，启用后桌面上会显示晾衣绳，支持添加录音 / 便利签 / 随手记 / 截图 / 本地图片 / 番茄计时卡片挂在晾衣绳上。
  • 截图复制后，截图会自动挂上晾衣绳（支持启用 / 停用）。
  • 优化桌面便利签功能，新建的便利签默认尺寸适当调大，且增加内容复制功能。
  • 晾衣绳首次安装默认关闭，手动启用后会记住设置；修复设置页在部分数据下无法打开的问题。
v0.4.80
  • 新增晾衣绳功能，启用后桌面上会显示晾衣绳，支持添加录音 / 便利签 / 随手记 / 截图 / 本地图片 / 番茄计时卡片挂在晾衣绳上。
  • 截图复制后，截图会自动挂上晾衣绳（支持启用 / 停用）。
  • 优化桌面便利签功能，新建的便利签默认尺寸适当调大，且增加内容复制功能。
v0.4.65
  • 修复部分网络环境下账号登录、云同步、激活码兑换失败的问题。
  • 修复工具内检查更新失败、下载安装包变成网页文件的问题。
  • 本次需手动覆盖安装一次，之后即可在工具内直接检查并自动更新。
v0.4.64
  • 修复多屏模式下，在桌面打开工具时没有即时显示窗口的问题。
  • 每次重启工具后，工具窗口从默认收起状态改为默认展开状态。
v0.4.63
  • 周待办/月待办每个日期上新增添加按钮，支持选择任一日期添加待办事项。
v0.4.62
  • 新增窗口位置配置：多屏使用时，允许用户自行选择工具窗口要显示在主屏还是副屏，且贴边方向支持选择要显示在屏幕右侧还是屏幕左侧。
  • 顶部导航栏新增截图/新建便利签/剪贴板三个功能入口，且支持在设置页面中调整顶栏快捷入口的顺序及是否显示。
v0.4.61
  • 截图识别修复：修复框选识别超过约 18 个字的长文案时结果错乱、无法识别的问题（检测对超宽扁条选区放大不足导致文字检测碎裂，现按高度补足放大，长短选区识别质量一致）。
  • 下载站新增功能详解、横向对比、常见问题、更新日志独立页面与结构化数据，优化搜索引擎收录与访问稳定性。
v0.4.60
  • 产品正式更名为 Tacco（应用名、下载页、后台品牌字全部同步；内部数据目录与账号体系保持兼容，老用户升级零丢失）。
  • 重复任务提醒时间优化：每个发生日各自套用系列默认时刻，支持单日例外，修复历史模板提醒串日问题。
  • 修复下载站多入口（todobar-app 与 sync.tuanzhang.site）截图缓存一致性。
早期版本（0.4.x）
  • 逐步补齐核心能力：贴边待办栏、日/周/月视图、生日与纪念日、内置计算器、黄历、云同步、牛马计薪器。
  • 桌面套件成型：截图钉屏与标注、剪贴板历史、桌面便利签、录音与转写。
  • 持续打磨贴边唤出体验与多设备同步稳定性。
