A

素瓷 · 侘寂

Editorial / wabi-sabi · 安静、手作、纸感

为什么适合

米白哑光瓷扣 + 麻绳 + 陶土绳结，和绳上的原木夹、米色纸卡是同一套材质语言。把手不是"一个 UI 按钮"，而像挂在绳上的一枚小瓷牌，收起态几乎融进壁纸。

取舍

得到：最耐看、最不抢眼，与现有晾衣绳零违和。
代价：对比度偏低，深色壁纸上需要浅色描边兜底；识别"可下拉"要靠底部那个小 V，比另外两款含蓄。

黄铜 · 铃坠

Heritage craft · 复古、有分量、金属光泽

为什么适合

把把手做成一枚老式窗帘绳的黄铜坠子：上端铜环、中段车刻横纹、下缘加厚收口，配深棕绞绳。它是三款里唯一"看起来就该被往下拽"的——重量感本身就是下拉的视觉提示。

取舍

得到：辨识度最高、最有"可以拉"的暗示，深浅壁纸都压得住。
代价：金色在米色纸卡体系里是新增的一个强调色，整体会稍显"精致物件"而非"随手贴的便签"。

C

琉璃 · 露珠

Luminous / dreamy · 通透、光感、最"唯美"

为什么适合

一颗挂在银蓝细丝上的露珠：上圆下尖的水滴轮廓、内部一枚柔光核、左上高光弧。它不像开关，更像凝结出来的一滴水，收起态在桌面顶部是一点很轻的亮。

取舍

得到：三款里最梦幻、最像"设计过"的一件，冷色调在深色壁纸上尤其出彩。
代价：与原木/纸张的暖调反差最大；为避免透明窗合成问题，通透感全部靠不透明渐变模拟，不能真用玻璃模糊。

实现约束（三款共通，选中后照此落地）

  • 沿用现有 DOM 骨架：.cl-pulltab > .cl-pull-cord / .cl-pull-bead / .cl-pull-tab，只换样式，Rust 侧零改动。
  • 布局锚点不变：480×96 命中盒、丝线居中 26px、把手 30×36 且 top 28、最大下移 27px（底边 91 < 96，不会被窗口裁掉）。
  • 所有表面用 不透明 渐变 / 实色描边；"通透感"靠渐变模拟，禁用 backdrop-filter、filter: blur、mix-blend-mode、isolation 与任何 alpha 动画。
  • 动效只写 transform（scaleY / translateY / rotate），进度由 --cl-pull 驱动；.is-pulling 关 transition 逐帧跟手，.is-released 负责回弹曲线。
  • 深色主题单独给一套描边/底色，保证在深色壁纸上仍有清晰轮廓。
  • hover 不改变任何合成属性（不改 transform / opacity / box-shadow / filter），避免与透明窗的合成层重绘冲突。
