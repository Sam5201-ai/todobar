晾衣绳 · 绳身皮肤 3 款设计提案

绳身（麻绳 + 两端固定钉）跟随「拉杆样式」配置项换肤：选哪款拉杆，绳与钉就自动换成同一套材质语言，入口不新增，仍在 设置 → 晾衣绳 → 拉杆样式。绳体几何完全不变（同一条下垂曲线、同一拖拽热区），只换颜色 / 材质 / 装饰；夹子随皮肤换装——A 原木夹、B 小铜铃夹、C 双滴小水滴夹。

实现方式：data-pulltab 选择器覆盖 CSS 变量 + SVG 装饰路径 红线遵守：零 filter / 零动画 / 零几何变化 深色主题：每款均给出暗色版实色
A
配 拉杆 A「素瓷·侘寂」

亚麻双股绳 · 陶土圆钉

未漂染的亚麻本色，纤维松软，钉是搓捏过的陶土

材质 tokens

主线 亚麻 #c2a473 底线 陶褐 #8a6a3e 陶土钉 #a98a5d 暗色主线 #a3875c

设计意图

现状麻绳已接近素瓷气质，本款做「贴色」微调：主线由偏黄的 #b7915e 调暖为米灰亚麻 #c2a473，与瓷扣 #f5efe2 同属一个暖色系；新增等距「绞股短纹」虚线强化双股麻绳的手搓感；两端圆钉从木质米色改为陶土色，与瓷扣底部的陶土绳结互为呼应。夹子保留原木夹——素瓷·侘寂语境里，亚麻绳 + 陶土钉 + 原木夹本来就是一套，木夹是 A 款的基准，也是 B / C 换装前的参照。

配 拉杆 B「黄铜·铃坠」

黄铜车刻杆 · 铜环钉 · 小铜铃夹

老式窗帘盒的黄铜横杆，车削出等距环纹，钉是穿绳的铜环，夹是一颗会响的小铜铃

材质 tokens

铜杆主色 #b8893c 车削高光 #f6e3ac 车刻环纹 #7a5824 铜环钉 #8a6a2d 铃身 #d6b061 檐口/铃舌 #f8e8b6 暗色主色 #9c7836

设计意图

绳子不再是「绳」，而是一根微下垂的黄铜横杆：主线用铜金色，上方叠一条 1.1px 的车削高光线模拟金属反光，再叠等距短划虚线作为车刻环纹（dasharray 2.4/26，纯虚线、零动画成本）；两端的麻绳圆钉换成带孔铜环——正是窗帘绳穿过的那个环。夹子换成「小铜铃夹」：整枚夹子就是一颗小铃铛——钟罩圆顶（74% 上拱的钟形圆角）、一道铜檐口、底下悬着半露的铃舌小圆珠，与铃坠拉杆本是同一串铃铛上的「坠」与「铃」，卡片仿佛是被一颗颗小铃铛别在铜杆上，风一吹（展开/收起动效）仿佛能听见轻响。

配 拉杆 C「琉璃·露珠」

银蓝丝线 · 缀露 · 水晶钉 · 双滴小水滴夹

更细的一根银蓝丝线，线上凝着几颗露珠，钉是釉面水晶，卡片被两颗等大的露珠对称夹着、微微相向而倾

材质 tokens

丝线 #a9c6ec 高光虚线 #ffffff 底线/露珠 #6f9fdd 水晶钉 #7fa8e0 水滴夹 #bcd7f6 暗色丝线 #7fa3cf

设计意图

丝线比麻绳更细（3.2 → 2.6px），颜色从暖棕切换为银蓝 #a9c6ec，白色高光虚线改为稀疏长划，像丝线受光；沿曲线缀 4 颗露珠（径向渐变玻璃圆：上白下蓝，各带 1px 暗蓝底线示意「挂」在丝线上），与拉杆的水滴琉璃扣同一语汇；两端钉换银蓝釉面水晶钉。夹子换成「双滴小水滴夹」：整枚夹子就是一颗露珠——圆滚滚的果冻水滴肚（56% 上拱的饱满弧线）、顶部一个细小尖嘴勾在丝线上（与拉杆水滴尖同款造型语言），左上斜一道白釉高光。每张卡片左右各一滴、两滴完全等大（14×20），以 ±8° 镜像倾角微微相向而倾，像两颗没滴下来的露水面对面替你捏着便签——对称、安稳又带一点互动感；丝线上另外缀的 4 颗静露与夹子的水滴互相呼应，整条绳是一根「清晨沾露的丝线」。

实现落点（供确认后开发参考，本次不改代码）

  • 入口不变：复用现有「设置 → 晾衣绳 → 拉杆样式」，选择 porcelain / brass / glass 时，绳窗根节点已有的 data-pulltab 属性同步驱动绳身与固定钉皮肤，无需新增配置项。
  • 改动范围：仅 [clothesline.css]（新增三段 .cl-root[data-pulltab=…] .cl-rope-* 变量/覆盖）与 [ClotheslineView.tsx] 的绳体 SVG（B 款增 2 条装饰 path、C 款增露珠 circle，均由同一条曲线坐标公式派生，其余几何不动）。
  • 夹子跟随换肤（关键差异）：三款夹子不再是同一个木夹——A 保留原木夹（15×32 木质，素瓷语境里木头是对的）；B 换小铜铃夹（16×24 钟形圆顶 + 檐口 + 悬晃铃舌，纯 CSS 圆角 + 渐变实现）；C 换双滴小水滴夹（14×20 等大 ×2，圆肚 + 上尖嘴勾线，±8° 镜像相向微倾，夹位 30% / 70% 左右对称）。实现上 .cl-clip 的悬挂定位逻辑不变，仅由 data-pulltab 切换造型类；C 款双夹为 .cl-clip 副本 ×2（left 百分比驱动 + ±8° 镜像 transform），不改卡片悬挂高度计算。
  • 几何与交互零变化：绳子仍是 viewBox 0 0 1000 64 / M4 26 Q500 46 996 26，拖拽热区、卡片悬挂高度计算（26+40·t(1−t)）全部共用，不改 Rust 侧任何窗口逻辑。
  • 红线遵守：三款均为纯色 / 渐变 / dasharray 实色装饰，不用 filter、backdrop-filter、will-change、动画——露珠与铜环钉用 SVG radialGradient 实色填充，规避透明窗合成层重建问题。
  • 深色主题：每款给出一套暗色实色（不用 filter 变暗），挂 [data-pulltab][data-theme='dark'] 双属性选择器，与拉杆皮肤深色覆盖同一写法。
  • 配置页预览：拉杆样式三选一的缩略图同步加上对应绳身小样，所见即所得。
