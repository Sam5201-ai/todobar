番茄钟卡片 · 6 款样式设计提案

用于 新建 / 编辑番茄计时弹窗 的「卡片样式」选择。A/B/C（怀表 / 车票 / 掌机）为上轮已确认方案，★掌机按钮文案已按反馈改为 暂停 / 小重置 / +5分；本轮新增 D/E/F 三款——依然在排版结构与卡片形态上完全不同：D 把整卡做成番茄罐头（金属罐顶 + 波普标签）；E 做成咖啡小黑板（木框 + 粉笔手写 + 正字计数）；F 做成剧场灯牌（灯泡边框 + 熄灯倒数）。全部款式按钮文案统一为 暂停 / 小重置 / +5分，内容元素与现有番茄卡一一对应：标题、倒计时 + 进度、三按钮、状态脚注。

尺寸：168 × 196（现番茄卡同规格） 红线：不透明背景 / 零 filter / 零动画 / 零 transition 实现：前 3 款复用 paper/minimal/glass，后 3 款新增 can/board/marquee，老数据零迁移

像素掌机 · LCD 屏 · 分段电量条

设计意图

「外壳套屏幕」的嵌套结构是三款里唯一的：卡片 = 塑料外壳（右上角圆角一大一小的老掌机轮廓），里面内嵌 LCD 屏（墨绿底 + 深橄榄字 + 暖灰屏框 + 右下角红色电源灯）；进度不用圆环，改成分段电量条（10 格 repeating-gradient，每分钟掉一格，像宠物机的饱食度）；标题变成屏幕上方一行像素标牌「◉ TOMATO-01 · 写周报」；三按钮保留掌机键帽质感（奶油色凸面 + 底部厚阴影），文案与其他款式统一为暂停 / 小重置 / +5分。等宽字 + tabular-nums 就是液晶数字的味儿，不用引字体。

番茄罐头 · 波普标签 · 容量条进度

设计意图

「罐头」是层叠横带结构：顶部一条金属罐顶（银灰渐变 + 拉丝环），罐身是左右两道圆柱明暗带的标签纸（纯横向渐变模拟圆罐立体感，不用任何 3D/filter）；标签正中一条通栏红色波普条写标题，下面大号衬线时间像罐头的净含量数字；进度做成「REMAINING 容量条」——红白相间的分段条从右往左消耗，旁边有营养标签式小注（62% LEFT）；三按钮做成红色印章椭圆票（实色浅底 + 红描边），文案 暂停/小重置/+5分。自定义卡色 → 染红色波普条，就是安迪·沃霍尔换一个颜色的罐头。

新增提案三

剧场灯牌 · 灯泡边框 · 熄灯倒数进度

小剧场门口的跑马灯牌：金色灯泡绕边一圈，时间像开演倒数

材质 tokens

灯牌深蓝 #27304a 灯泡金 #e8b34b 灯字暖白 #fff8e6 熄灯灰蓝 #3a4360 暗色灯牌 #1c2233

设计意图

全场唯一一款天生深色的卡片：整卡是剧场灯牌，四周一圈金色 dotted 圆点边框（一行 CSS 的 dotted border 就是灯泡串，纯静态不闪烁）；标题是「◆ 今日场次 ◆」式金色字距标牌；时间用大号等宽暖白字 + 一点静态灯字晕染（双层 text-shadow，不违反零 filter 红线）；进度独此一家——灯泡倒数：一排 10 颗小灯泡，亮着的代表剩余分钟，每过 1 分钟熄灭一颗（亮灯 = 金色径向渐变 + 柔光 box-shadow，熄灯 = 灰蓝凹陷），比电量条更有仪式感；三按钮是金边灯牌胶囊，文案 暂停/小重置/+5分。自定义卡色 → 染灯泡与标牌的暖金色相（红牌/蓝牌/绿牌剧场）。

实现落点（供确认后开发参考，本次不改代码）

  • 入口扩展：番茄弹窗「卡片样式」由三选一扩为六选一（怀表 / 车票 / 掌机 / 罐头 / 小黑板 / 灯牌）。前 3 款复用现有 data-style 值（paper→怀表 / minimal→车票 / glass→掌机），后 3 款新增值 can / board / marquee；老数据零迁移（旧值继续渲染新皮肤），已挂旧卡片自动获得新样式。
  • 排版重构：六款各自重排 .cl-face（怀表=圆盘主体、车票=票头+票身横版、掌机=外壳嵌套屏幕、罐头=罐顶+通栏标签横带、黑板=木框中框、灯牌=灯泡边框），进度环 SVG 复用现有 cl-tm-svg，怀表加装饰刻度圆，掌机改分段条、罐头改容量条、黑板改正字行、灯牌改灯泡行（其余隐藏圆环）。
  • 按钮语义不变：六款按钮文案统一为 暂停/小重置/+5分，事件逻辑零改动，仅键面材质随皮肤变化。
  • 自定义卡色：card_color 继续生效——怀表染表圈铜牌、车票染票头横条、掌机染外壳、罐头染波普红条、黑板染木框、灯牌染灯泡金色相，屏幕/票纸/板面保持固定色保证可读性。
  • 红线遵守：全部不透明背景（color-mix 不透明版 / 实色渐变），零 filter、零 backdrop-filter、零动画零 transition；打孔边用 radial-gradient 实色圆点（孔色=墙色变量，非 alpha）。
  • 深色主题：每款一套暗色实色（[data-theme='dark'] 双属性选择器），LCD 屏本身即深色，暗色下仅外壳与屏框加深。
  • 尺寸不变：168 × 196（现番茄卡规格），三按钮 9.5~10px 不换行，300px 窄视口约束继续满足。
